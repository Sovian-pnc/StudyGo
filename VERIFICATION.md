# Проверка сборки StudyGo v6

Дата проверки: 2 августа 2026.

## Пройдено

- JavaScript `app.js`, `approved-v5.js`, `portal.js` и серверная функция `api/consultation.js` проверены на синтаксис.
- Все локальные пути к HTML, CSS, JavaScript и изображениям разрешаются.
- Все внутренние ссылки и якоря между основными страницами разрешаются.
- Отдельно проверены страницы `index.html`, `about.html`, `services.html`, `passport.html`, `admin.html` и миграция для существующей базы.

## Что сознательно не было опубликовано автоматически

- В подключённом Vercel-проекте `studygo-platform` есть предыдущая production-сборка другого Next.js-проекта, которая сейчас падает на отсутствующем компоненте `CatalogPreview`. Текущая статическая сборка не была подменена поверх неё без отдельного подтверждения.
- GitHub-коннектор не имеет доступа к репозиторию, из которого Vercel пытается собрать старый проект.
- В Supabase уже есть проект `studygo` с 167 учреждениями. Для него подготовлена безопасная аддитивная миграция `supabase/migrations/20260802_studygo_admin_portal.sql`, но она не применена автоматически: миграция меняет таблицы, права доступа, RLS-политики и Storage.

## Перед публикацией

Следуйте `DEPLOYMENT_MANUAL.md`. Для нынешней базы используйте именно аддитивную миграцию, а не стартовый `schema.sql`.
