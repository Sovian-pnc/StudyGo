# StudyGo v6 — сайт для будущих студентов Китая

Адаптивный сайт в утверждённой визуальной системе StudyGo: глубокий индиго, фиолетовые акценты, салатовая атмосферная строка, молодёжный кампусный вайб, реальный каталог и понятная структура пути поступления.

Главная не перегружена: доверие и услуги вынесены на самостоятельные страницы. В проекте также подготовлены прототипы личного пространства ученика и редактора контента, а для команды — схема защищённой базы Supabase.

## Страницы

| Страница | Назначение |
| --- | --- |
| `index.html` | Главная, умный каталог, пять маршрутов, статьи, FAQ, компактный блок «Китай сейчас». |
| `about.html` | О компании, Павел Чугунов, принципы проверки и доверия. |
| `services.html` | Отдельная страница «Цены и услуги»: услуги StudyGo в USD, расходы вуза отдельно в RMB. |
| `passport.html` | StudyGo Passport — будущий кабинет ученика, анкета и чек-лист документов. |
| `admin.html` | Демонстрационный редактор карточки: поля и живой предпросмотр без правки кода. |

## Что работает сейчас

- шапка, desktop/mobile-меню и все основные переходы между страницами;
- умный каталог: поиск, фильтры, тип учреждения (школа / колледж / университет), избранное и сравнение;
- карточка учреждения с программами, городом, источниками, фото и блоком поступления;
- динамичный счётчик базы и аккуратная медленная строка в одну линию;
- компактный «Китай сейчас»: автоматически и по клику меняет Гуанчжоу, Шэньчжэнь, Пекин и Шанхай, показывает локальное время и получает погоду из Open-Meteo;
- цифровой гид **StudyGo**; в визуализации использована предоставленная семье StudyGo фотография Арины как образ будущей студентки, а имя гида остаётся StudyGo;
- личный Passport: интерфейс анкеты, чек-лист документов и локальный черновик;
- редактор контента: изменение названия, города, типа, цены и фото с моментальным предпросмотром; черновик хранится **только в текущем браузере** и не публикуется;
- отдельная карточка руководителя: Павел Чугунов и подтверждённая пользователем информация о фонде «Дари Добро»;
- консультационные формы: после настройки Vercel и Supabase создают запись в базе через серверную функцию. До настройки честно показывают режим демо и не имитируют отправку.

## Локальный просмотр

Откройте терминал в папке проекта и выполните:

```bash
python3 -m http.server 8080
```

Затем откройте `http://localhost:8080`. Через `file://` не будет работать сетевой запрос погоды и проверка формы.

## База, кабинет и редактор

Файл `supabase/schema.sql` создаёт таблицы каталога, медиа, Passport, документов и заявок с включённым Row Level Security. При создании пользователя Supabase автоматически создаёт его профиль; опубликованный каталог видит только записи со статусом `verified`.

В текущей версии `admin.html` — это безопасный UX-прототип: он не является публичной авторизацией и не даёт никому доступа к базе. Когда Supabase будет подключён:

1. Команда входит через Supabase Auth.
2. Администратор получает роль `admin` в `profiles`.
3. Публикация из редактора идёт в `institutions` и `institution_media`.
4. Фото загружаются в закрытый Storage bucket и получают подпись/лицензию.
5. Ученик видит только свои паспорт и документы.

Никогда не размещайте `SUPABASE_SERVICE_ROLE_KEY` в браузерном JavaScript, HTML или публичном репозитории. Он используется только серверной функцией Vercel.

## Развёртывание

Подробная инструкция находится в [`DEPLOYMENT_MANUAL.md`](DEPLOYMENT_MANUAL.md).

Коротко:

1. Загрузите содержимое этой папки в новый GitHub-репозиторий.
2. Импортируйте репозиторий в Vercel как **Other**; команды сборки не нужны.
3. Для рабочих заявок: на пустом Supabase-проекте запустите `supabase/schema.sql`; для уже созданного StudyGo-проекта с каталогом — только `supabase/migrations/20260802_studygo_admin_portal.sql`. Затем добавьте в Vercel серверные переменные из `.env.example`.

`vercel.json` не требуется: статические страницы и папка `api/` поддерживаются Vercel по умолчанию.

## Данные и фотографии

Каталог — рабочая стартовая база, но не обещание условий приёма. До публикации каждого учреждения необходимо перепроверить официальные требования, сроки, цену, доступность для иностранцев, правила для несовершеннолетних и право на каждую фотографию. Источники и статусы медиа — в [`ASSET_CREDITS.md`](ASSET_CREDITS.md) и [`external-image-urls.txt`](external-image-urls.txt).

Визуализации StudyGo нельзя выдавать за документальные фотографии конкретного учреждения. Для коммерческого запуска используйте официальный пресс-кит, письменное разрешение или совместимую открытую лицензию.
